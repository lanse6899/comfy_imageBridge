# 🔵BB桥接预览 (ImageBridgeX)

一个基于 Impact Pack 的 PreviewBridge 节点复刻的临时能够使用图像桥接预览节点。Impact Pack 如果可以使用后请使用它的。

<img width="982" height="693" alt="ScreenShot_2025-12-12_132527_721" src="https://github.com/user-attachments/assets/dafc6f84-e464-4f53-bf66-28ef35cfdee9" />


### 基本使用

1. **添加节点**
   - 在 ComfyUI 节点菜单中找到 "🔵BB桥接预览"
   - 将节点添加到工作流中

### 重要提示

**第一张图像运行时画遮罩可以正常使用，如果想要第二次图像加载绘制遮罩请先清理 `image` 中的选项内容，绘制遮罩即可运行或再次即可！**
